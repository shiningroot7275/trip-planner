# 여행 플래너

휴대폰(아이폰)에 맞춘 여행 계획 웹 페이지입니다. 파일 하나(`index.html`)로 동작하며 서버나 계정이 필요 없습니다. 예시로 2027년 1월 21~24일 홍콩 여행과 홍콩 장소 12곳이 들어 있습니다.

## 기능

- 지도: 확대, 축소, 이동, 장소 검색, 지도를 길게 눌러 장소 추가
- 장소 정보: 이름, 분류, 요일별 운영시간, 요금, 주소, 운영시간 출처와 확인한 날
- 이동시간: 지도에서 두 장소를 차례로 누르면 도보, 대중교통(추정), 차량 시간
- 시간표: 장소를 끌어다 놓아 일정 만들기, 일정 사이 이동시간과 운영시간 경고
- 항공권: 현지 시각으로 입력하면 시차를 계산해 시간표에 표시
- 일차별 동선 지도, 준비물 목록, 현재 위치
- 공유 링크와 백업 파일로 다른 기기나 동행자에게 일정 넘기기

## 저장과 공유

- 일정은 각 기기의 브라우저에 저장됩니다. 서버로는 보내지 않습니다.
- 공유 링크에는 링크를 만든 순간의 일정 전체가 들어 있습니다. 이후 수정 내용은 새 링크를 보내야 반영됩니다.
- 아이폰 Safari는 7일 동안 열지 않은 사이트의 저장 자료를 지울 수 있으니, 중요한 단계마다 백업 파일이나 공유 링크를 남겨 두세요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 페이지. `src/12_build.sh`가 만든다 |
| `src/01_head.html` ~ `src/11_init.js` | 페이지 조각. 번호 순서대로 이어 붙인다 |
| `src/04_make_seed.py` | `data/` 의 조사 자료로 `src/04_seed.js`(예시 장소)를 만든다 |
| `src/12_build.sh` | 조각을 이어 붙여 `index.html`을 만든다 |
| `data/01_places_hk_2027-01.json` | 홍콩 예시 장소 조사 자료 (2026-11-18 확인) |

고친 뒤 다시 만들기:

```sh
python -I src/04_make_seed.py data/01_places_hk_2027-01.json src/04_seed.js
sh src/12_build.sh
```

## 자료 출처와 계산 방법

- 지도: © OpenStreetMap 기여자
- 장소 검색: OpenStreetMap Nominatim
- 도보·차량 시간: FOSSGIS OSRM 경로 서버(routing.openstreetmap.de)의 도로망 계산값. 차량은 교통 혼잡을 반영하지 않습니다.
- 대중교통 시간(추정): 도보와 차량 경로거리 가운데 짧은 쪽을 평균 속도(시속 약 20~40km)로 나눈 값에 역까지 걷기와 대기 10분을 더했습니다.
- 예시 장소 운영시간: 장소마다 출처와 확인한 날을 적었습니다. 여행 전에 공식 사이트를 다시 확인하세요.
