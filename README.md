# 여행 플래너

휴대폰(아이폰)에 맞춘 여행 계획 웹 페이지입니다. 파일 하나(`index.html`)로 동작하며 서버나 계정이 필요 없습니다.

- 주소: https://shiningroot7275.github.io/trip-planner/
- 예시: 2027년 1월 21~24일 홍콩 여행, 홍콩 장소 34곳(명소, 맛집, 바, 쇼핑, 교통), 예시 시간표 10개

## 기능

- 지도: 확대, 축소, 이동, 장소 검색, 지도를 길게 눌러 장소 추가
- 검색 자동 입력: 검색한 장소를 고르면 운영시간, 전화번호, 웹사이트, 음식 종류를 OpenStreetMap 자료로 채움 (자료가 있는 장소만, 출처 함께 표시)
- 장소 정보: 이름, 분류(명소, 식당, 카페·디저트, 바, 쇼핑, 숙소, 교통, 기타), 요일별 운영시간, 요금, 주소, 운영시간 출처와 확인한 날
- 이동시간: 지도에서 두 장소를 차례로 누르면 도보, 대중교통(추정), 차량 시간
- 시간표: 장소를 끌어다 놓아 일정 만들기, 일정 사이 이동시간과 운영시간 경고
- 항공권: 현지 시각으로 입력하면 시차를 계산해 시간표에 표시
- 일차별 동선 지도, 준비물 목록, 현재 위치
- 공유 링크와 백업 파일로 다른 기기나 동행자에게 일정 넘기기
- 예시 장소가 늘어나면 이미 고친 일정에도 새 장소만 한 번 들어감 (지운 예시 장소는 다시 생기지 않음)
- 화면: 흰 바탕이 기본이고, 더보기에서 어두운 화면을 고를 수 있음

## 저장과 공유

- 일정은 각 기기의 브라우저에 저장됩니다. 서버로는 보내지 않습니다.
- 카카오톡 안 브라우저, Safari, Chrome은 저장소가 서로 다릅니다. 한 브라우저를 정해서 쓰세요.
- 공유 링크에는 링크를 만든 순간의 일정이 들어 있습니다. 일정을 고친 뒤에는 새 링크를 다시 보내야 합니다.
- 받은 링크를 열면 받는 사람의 일정이 그 내용으로 바뀝니다. 받는 사람이 그 일정을 고친 적이 있으면 바꿀지 먼저 묻습니다.
- 링크가 열리지 않으면 더보기의 "백업 파일 저장"으로 파일을 보내고, 받는 사람은 "백업 파일 불러오기"로 엽니다.
- 아이폰 Safari는 오래 열지 않은 사이트의 저장 자료를 지울 수 있으니, 중요한 단계마다 백업 파일이나 공유 링크를 남겨 두세요.

## 문제가 생겼을 때

- **먼저 페이지 버전을 확인하세요.** 더보기 맨 아래 "자료 출처와 계산 방법"에 페이지 버전이 있습니다.
- **새 버전이 올라오면 "새 버전이 나왔습니다" 안내가 뜹니다.** 새로 고침을 눌러 주세요. 일정은 그대로 남습니다.
- **새로 고쳐도 예전 화면이면 10분쯤 뒤 다시 열어 주세요.** 주소 끝에 `?v=` 뒤로 아무 숫자나 붙여 열어도 됩니다.
- 그래도 해결되지 않으면 문제가 생긴 화면과 페이지 버전을 함께 알려 주세요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 페이지. `src/12_build.sh`가 만든다 |
| `src/01_head.html` ~ `src/11_init.js` | 페이지 조각. 번호 순서대로 이어 붙인다 |
| `src/04_make_seed.py` | `data/`의 조사 자료로 `src/04_seed.js`(예시 장소)를 만든다 |
| `src/12_build.sh` | 조각을 이어 붙이고 페이지 버전을 넣어 `index.html`을 만든다 |
| `data/01_places_hk_2027-01.json` | 홍콩 예시 장소 조사 자료, 묶음 1의 12곳 (2026-11-18 확인) |
| `data/02_places_hk_more_2026-11.json` | 더한 맛집, 바, 명소 22곳 조사 자료, 묶음 2 (2026-11-20 확인, 국문 안내 포함) |
| `tests/01_osm_hours_test.js` | 운영시간 읽기 시험 (`node tests/01_osm_hours_test.js`) |
| `tests/02_seed_merge_test.js` | 예시 장소 묶음 넣기와 공유 링크 시험 (`node tests/02_seed_merge_test.js`) |
| `docs/01_개발_안내.md` | 구조, 고치고 올리는 순서, 공유 링크 형식, 지금까지 겪은 문제와 해결 |

고친 뒤 다시 만들기:

```sh
python -I src/04_make_seed.py src/04_seed.js data/01_places_hk_2027-01.json data/02_places_hk_more_2026-11.json
sh src/12_build.sh
```

## 자료 출처와 계산 방법

- 지도: © OpenStreetMap 기여자 (OpenStreetMap 표준 타일)
- 장소 검색: OpenStreetMap Nominatim
- 도보·차량 시간: FOSSGIS OSRM 경로 서버(`routing.openstreetmap.de`)의 도로망 계산값. 차량은 교통 혼잡을 반영하지 않습니다.
- 대중교통 시간(추정): 도보와 차량 경로거리 가운데 짧은 쪽을 평균 속도(시속 약 20~40km)로 나눈 값에 역까지 걷기와 대기 10분을 더했습니다.
- 예시 장소 운영시간: 장소마다 출처와 확인한 날을 적었습니다. 공식 자료가 없는 곳은 "기타 출처 확인"으로 표시했습니다. 여행 전에 공식 사이트를 다시 확인하세요.
- 예시 장소 좌표: OpenStreetMap에서 찾은 가게나 건물 위치입니다. 건물 안 매장(쇼핑몰, 공항)은 건물 위치입니다.
- 블로그 추천 장소 7곳은 메모에 "추천 출처: 네이버 블로그 홍콩 맛집 정리 글"을 적고, 블로그에서만 확인된 내용은 "블로그 후기"로 구분했습니다.
